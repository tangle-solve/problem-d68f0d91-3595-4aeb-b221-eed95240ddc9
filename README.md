### ALGO-000179: Positivity of arbitrary linear recurrences
- **Subfield:** Games, automata, and verification
- **Open:** Decide whether every term of a given rational linear recurrence sequence is nonnegative.
- **Status:** Decidable for several low-order and structurally restricted classes; the unrestricted problem remains open.
- **Type:** theory
- **Why:** Captures invariant checking and safety of linear dynamical systems.
- **Key works:** Ouaknine and Worrell (2014), *Positivity Problems for Low-Order Linear Recurrence Sequences*; *On the Positivity Problem for Simple Linear Recurrence Sequences*, arXiv:1309.1550.
- **Related:** Control theory—positivity and invariant regions.
